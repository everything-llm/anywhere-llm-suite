AnywhereLLM Suite

AnywhereLLM Suite is a personal, open-source set of tools that lets an AI agent running on a self-hosted AnythingLLM server do more on its owner's behalf: browse, keep notes, build small apps, and call other services' APIs with sign-ins the owner approves.

It has three parts: agent skills that run inside AnythingLLM, a small bridge that lets the AnywhereLLM Lite phone app reach the server, and the sign-in pages (the Vault and the Library) where the owner gives or removes access.

It runs only on the owner's own server. It is not a hosted service, has no accounts of its own, and collects no analytics.

Source code and issues: github.com/BinaryBand/anywherellm-suite.
